# Facebook Clone Website

This is a **Facebook Clone Website** created as part of my **Git and GitHub tutorial/practice project**. The main purpose of this project was to understand how Git works in a real development workflow while building a simple social-media-style website.

## 📌 About the Project

The project is inspired by the basic layout and features of Facebook. It provides a social media-style interface where users can explore different sections of the website and interact with the available UI elements.

This project was developed mainly for **learning and practice purposes**. It helped me understand both website development concepts and the practical use of Git for managing source code and project versions.

## 🎯 Purpose of the Project

The main objectives of this project are:

- To practice creating a website with a social-media-style interface.
- To understand the basic structure of a web project.
- To learn how to use Git for version control.
- To practice creating commits and maintaining project history.
- To understand Git branches and branch management.
- To practice pushing a project to GitHub.
- To understand how Git can be used during real software development.

## 🛠️ Technologies Used

The project was created using web development technologies such as:

- **HTML** – Used to create the structure of the website.
- **CSS** – Used for styling and designing the user interface.
- **JavaScript** – Used where required to add basic interactivity.
- **Git** – Used for version control and tracking changes.
- **GitHub** – Used to store and manage the remote repository.

## 🔀 Git Practice

One of the main purposes of this project was to practice Git commands and understand a basic Git workflow.

During development, Git was used to:

```bash
git init
git status
git add .
git commit -m "Initial commit"
git branch
git switch
git merge
git push
git pull
```

I also learned about concepts such as:

- Repository
- Working directory
- Staging area
- Commit
- Branch
- Merge
- Rebase
- Remote repository
- `origin`
- `main` branch
- GitHub
- SSH authentication
